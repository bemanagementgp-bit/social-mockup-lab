How to make a fake WhatsApp chat (or any mockup) in a minute

  1. Pick a type. Use the segmented control in the panel: WhatsApp, iMessage, Instagram, X or Notifs. Each one loads a realistic sample so you see a finished screen immediately.
  2. Edit the content. Change the contact name, status line, avatar and wallpaper. Add messages, flip them between sent and received, set the time and the tick state, and reorder with the arrows.
  3. Set the look. Toggle dark mode and the phone frame with Dynamic Island. Instagram and X mockups accept your own image or a clean gradient placeholder.
  4. Export. Download a PNG, copy it straight to the clipboard, or (Pro) export at 2x/3x, with a transparent background, or as a ZIP that contains one frame per message for animated reveals.

How to make a mockup look real

Realism comes from small details, not from the bubbles themselves. Keep timestamps consistent: replies arrive a minute or two apart, and a late-night chat should not show "9:41" everywhere. Use read receipts logically: in WhatsApp the last sent message is often only "delivered" (grey ticks) while earlier ones are "read" (blue). Write the way people actually type: short lines, lowercase, the occasional typo, an emoji, a message split in two. Match the status line to the moment ("typing…" for an unanswered question, "online" for a live exchange). Choose a wallpaper and theme that fit the person: dark mode with a plain wallpaper reads as a developer, the default doodle as everyone else. For Instagram and X, keep counts plausible for the account size and let the caption include a hashtag or two. Finally, export with the phone frame when the image will sit inside a design, and without it when it should pass as a native screenshot.
